# ELearning-Platform
Web Tech Workshop Final Project : React.Js based Frontend

Team No. 17

Project 33: E-learning Platform Frontend

Abstract
Build a complete e-learning platform frontend using React with course listings and detailed
course pages, integrated video player with playback controls, progress tracking for individual
lessons and overall course completion, interactive quiz components with immediate
feedback, and user dashboard showing enrolled courses. The application will utilize React
hooks for state management, component lifecycle methods for data fetching, and props for
component communication. This project demonstrates building a complex, production-ready
React application.

Tools and Technologies
* React: Components, hooks (useState, useEffect, useContext)
* React Router: Navigation and routing
* Axios or Fetch API: HTTP requests
* React Player: Video playback component
+ Context API: Global state management
+ CSS Modules or Styled Components: Styling
» localStorage: Save progress locally

Difficulty Level
Advanced
